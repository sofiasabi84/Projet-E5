💄 Cosmetic - Site E-commerce (Architecture MVC)

🎯 Objectif du projet

Développement d’un site e-commerce complet dédié à la vente de produits cosmétiques.
Le projet vise à proposer une plateforme fonctionnelle permettant la gestion des utilisateurs, des produits et des commandes.

---

🧱 Architecture

Le projet est basé sur une architecture **MVC (Model - View - Controller)** :

* **Model** : gestion des données et interaction avec la base SQL
* **View** : interface utilisateur (HTML, CSS)
* **Controller** : logique métier et traitement des requêtes

---

 🛠️ Technologies utilisées

* **PHP 8**
* **MySQL**
* **HTML / CSS**
* **JavaScript**
* Serveur local : XAMPP / WAMP

---

🗃️ Base de données

Base de données relationnelle permettant de gérer :

* Utilisateurs (clients)
* Produits
* Commandes
* Détails des commandes

Exemple de tables :

* `users`
* `products`
* `orders`
* `order_items`

---

⚙️ Fonctionnalités principales

* 🔐 Inscription / Connexion utilisateur
* 🛍️ Catalogue de produits
* 🛒 Gestion du panier
* 📦 Passage de commande
* 📊 Gestion des données via base SQL
* 🧑‍💼 Interface administrateur 

---

 📊 Exploitation des données

Ce projet permet d’analyser :

* Les ventes par produit
* Le comportement des utilisateurs
* Les performances commerciales

👉 Possibilité de connecter les données à des outils comme Power BI pour créer des dashboards.

---

 📈 Résultats / Apports

* Mise en place d’une structure MVC propre et maintenable
* Gestion complète d’un flux e-commerce
* Manipulation et structuration de données SQL
* Base exploitable pour analyse BI
